# Retrieval guide

Useful query form:

`<component> <operation> <solver/metric> <symptom/constraint>`

Examples:

- `发夹滤波器 reconstruction history replay topology face ID`
- `hairpin filter frequency domain S11 S21 mesh convergence`
- `CST discrete port invalid face recovery`

Ranking favors exact title/alias matches and validated status. Always inspect status and evidence; ranking score is relevance, not truth probability.
