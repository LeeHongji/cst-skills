# 给 Agent 的安装任务入口

本文件用于尚未安装 Skills 的 Agent。用户无需执行终端命令。读取本仓库 `skills/cst-research/SKILL.md` 和 [完整安装规程](../skills/cst-research/references/installation.md)，由你执行检查、安装、初始化和验证。

用户提供本仓库位置、研究工作区以及所用客户端后，即可开展安装。只缺少工作区位置时，请确认保存位置；不要把分发仓库当作研究目录。仅用 Codex 时只配置 Codex，不要求用户先安装 Claude Code。未指定研究课题时，只初始化空工作区。

## 安装边界

- 本仓库是安装来源，工作区是用户数据位置，运行时是另一个版本化位置。
- 使用官方 `npx skills add` 复制安装全部十个 Skills。
- 使用已安装入口 Skill 的 `bootstrap.py` 部署 MCP 和数据布局。
- 由本仓库附带的校验归档部署独立版本化运行环境，使用工作区部署记录绑定的 Python。
- 不替用户完成客户端信任、伪造模型批准、启动未请求的求解，或修改全局 MCP 设置。

完整规程包含命令模板、依赖检查、重复安装处理、配置保留、客户端验证和失败处理。不要只完成 CLI 安装就报告 MCP 已就绪。

## 给用户的交付

用普通语言给出：研究目录、安装和初始化结果、两个服务的后台检查结果、当前对话实际工具可用性、是否需要一次客户端操作。把“后台检查通过、等待客户端加载”和“当前对话已能调用工具”分开。

安装后打开或链接 [研究者指南](QUICKSTART.md)，告诉用户可以直接发研究需求，不要求其手动写命令、创建合同或选择内部工具。

真实客户端验收状态以 [验收报告](ACCEPTANCE.md) 为准；本文件不是所有客户端加载或批准交互已通过的声明。
