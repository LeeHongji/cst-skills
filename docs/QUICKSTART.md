# 研究者使用指南：在对话中开展微波研究

这份指南给研究者阅读。安装、文件创建、建模脚本和工具调用由 Agent 执行；你不需要打开终端，也不需要记住函数名。你需要选择研究目录、提出研究目标、审查模型，并对重要的工程取舍作出判断。

当前工具包用于 Windows 上的 CST 研究。日常入口是你使用的 Agent 对话，模型审查使用生成的三维页面，结果通过曲线、指标表和文件链接展示。它不是另一个独立工作台软件。

## 1. 第一次使用：把安装任务交给 Agent

将仓库地址提供给具备命令执行和工作区读写能力的 Agent，然后发送：

> 请按照这个仓库的 README 和 docs/AGENT_SETUP.md 安装完整的 CST Skills 与 MCP。我使用 Codex。研究资料的保存位置先与我确认，再自行完成依赖检查、安装、初始化和连接验证。保留已有数据。这次只安装，不进行求解；需要我在客户端操作时，请告诉我具体步骤。

仓库提供安装资源，研究工作区保存课题与结果；两者分别管理。研究工作区的位置和名称由你选择。

Agent 应给你一份简单的结果说明：

- 研究数据放在哪里。
- Skills 是否已安装，两个 MCP 服务是否通过连接检查。
- 你是否还需要在客户端打开研究目录、启用项目配置或重新连接。
- 哪些检查尚未完成，以及下一步是什么。

如果需要点击“信任项目”、启用 MCP 或重新打开对话，按 Agent 的说明在客户端完成即可。配置文件已经由 Agent 生成，不需要你手动编辑。当前客户端可能需要重新加载后才能发现新装的 Skills 和工具。

安装完后可以说：

> 我已经在客户端打开这个研究工作区。请检查当前对话能否实际调用研究工具和 Brain，告诉我是否可以开始课题。不要把后台连接测试当成当前对话已经连接成功。

如果你的 Agent 只能聊天、没有命令执行和工作区读写能力，它不能直接完成安装；请使用具有这些能力的 Agent。

## 2. 新建课题：说研究需求即可

你不必先建立复杂目录，也不必自己拟定所有参数。提供论文、结构图和目标即可。示例：

> 使用 cst-research，新建一个“方形开路谐振器宽带移相器”课题。附件是参考论文和结构草图。我希望沿用 3 GHz、2.74–3.20 GHz 的工作频带，主路和参考路都换成方形开路谐振器。先读懂论文的综合方法，整理现有经验，明确移相误差、插损、回波、材料和制造要求。没有确定的信息列出来和我确认。先给研究路线，再开始建模；CAD 审查前不要求解。

上述频带只属于这个示例，不是工具包的默认指标。相位误差、损耗与回波容限必须由本课题确认；不能把“按论文要求”代替具体数值。

Agent 应先告诉你：研究什么、如何判断成功、有哪些已知条件、哪些问题需要确认，以及第一轮准备做什么。它会创建课题和模型文件，检索本工作区的知识库。公开知识种子不等于你过去全部研究经验已经导入。

暂时没有完整指标也可以开始：

> 我想探索一种新滤波器结构，还没有完整指标。请先根据附件帮我梳理可行性、需要确认的信息和最小验证案例，暂时不要进行大规模优化。

## 3. 研究路线：每一步回答一个具体问题

滤波器与滤波移相器通常按下面的顺序推进。Agent 要根据实际课题调整，并解释跳过某一步的依据。

| 阶段 | 主要问题 | Agent 应展示的内容 |
|---|---|---|
| 理论与综合 | 论文的结构为什么工作？需要哪些谐振模式和耦合？ | 理论依据、计算结果、初始尺寸和待验证假设 |
| 单个谐振器 | 目标谐振是否出现？尺寸变化影响哪些模式？ | 单元 CAD、谐振曲线；支持时提供特征模证据 |
| 双谐振器 | 间距和相对位置能否实现所需耦合？ | 耦合结构、频率分裂或耦合趋势与适用条件 |
| 馈电 | 馈线、端口和外部耦合是否合适？ | 馈电 CAD、回波与外部耦合的验证结果 |
| 单支路滤波器 | 通带、回波、插损和阻带是否满足目标？ | 全频带曲线、指标最差值、仍需调整的参数 |
| 移相器集成 | 两条支路在同一频带是否实现目标相移？ | 两支路幅度、相位差、相位误差和滤波表现 |
| 最终确认 | 最佳候选能否经新的仿真再次通过？ | 独立确认曲线、收敛证据和可复查的模型 |

当前版本不保证支持通用特征模、场图或远场导出。Agent 必须先检查能力；缺失时明确告诉你该步骤尚未确认，提出可以执行的替代验证或适配器开发方案。替代验证不能冒称已做特征模。

对于移相器，不应只看中心频率的相位。必须在共同工作频带内检查相位差、损耗、回波，并使用一致的端口顺序与参考面。先使单个分支具备较好滤波表现，再讨论另一分支的带宽、相位斜率和集成调整。

## 4. CAD 审查：你看结构，Agent 解释结构

Agent 会打开或提供一个三维模型审查页，并解释导体、基板、地、馈线和端口分别是什么。你可以旋转、缩放模型，也可以让 Agent 定位某处结构。

可以直接指出问题：

> 输入馈线似乎穿进了谐振器，请放大该处，说明原本的耦合方式，并检查导体是否相连。

> 检查所有传输线直角弯折，根据已有验证经验设置 45 度斜切，并重新给我审查修改后的结构。

Agent 修改后应给你新版本。自动几何检查通过不代表微波性能已通过，也不能代替你的结构判断。

审查完成后，Agent 应给出明确的批准内容：模型版本、待变化参数及范围、固定条件、本轮预算。你的答复可以是：

> 我已审阅你刚展示的模型。同意只在你列出的参数范围内开展这一轮实验，其他条件固定；超范围或改结构时重新给我审查。

Agent 会通过当前支持的确认机制记录你的批准，并检查它是否对应刚审查的模型和参数范围。不能只写一句“用户已批准”就开始求解。如果当前客户端无法记录批准，Agent 应明确告诉你阻断在哪里；不能假装成功或替你确认。

## 5. 优化过程中，你怎样指导 Agent

批准后，Agent 在范围和预算内逐次求解、比较候选。你不需要盯着每一个参数，可以规定优先级：

> 优先改善单支路的带内回波，保持原来的通带范围。每轮展示最佳结果与上一版的叠加曲线，说明改善在哪里、代价是什么。连续三次没有改善时停止这轮尝试，给我两个下一步方案。

> 目前相位很好，先保留这版为基线。后续调整必须同时满足原相位误差要求，再改善滤波；不要用相位退化换取更好的回波。

> 这轮先限制为六次求解。结束后向我汇报最好的候选，即使没有达标也要保留结果和失败原因。

也可以随时查询：

> 目前在执行哪一步？完成了几次求解？最佳结果比基线改善了什么？给我现有曲线，不要等全部结束才展示。

停止时可以说：

> 不再提交下一次求解。保留当前结果，说明正在运行的任务状态和安全停止方式。

这套工具不保证即时中断正在运行的求解。Agent 应根据实际支持情况处理；不能关闭与你无关的 CST 进程。对话期间可查询进度，但当前分发包不提供独立任务看板，也不保证关闭 Agent 后继续自主研究。

## 6. 怎样验收一个结果

当 Agent 说找到好结果时，可以发送：

> 对当前最佳候选执行一次新的独立确认。给我完整频带曲线、各项指标最差值、收敛情况和模型文件。检查是否是真正的新求解，导出文件是否齐全，以及归档模型能否不依赖原结果缓存重新打开。最后逐项说明哪些目标通过、哪些未通过。

你应拿到：

- CAD 和模型文件，可用于继续研究。
- 可复查的导出曲线，以及基线、候选与确认结果的对比图。
- 全频带指标表，明确通过和未通过的项目。
- 收敛、设置和实验记录。
- 有证据支持的经验、适用范围和下一步建议。

“求解完成”和“设计达标”是两件事。Agent 必须分别报告；未达标也应交付完整结果，不能擅自放宽指标后宣称成功。

## 7. 下次继续、新建其他课题或沉淀经验

继续同一课题：

> 使用 cst-research 继续“方形开路谐振器宽带移相器”。先读当前最佳模型、最近的结果和未解决问题，给我一份简短状态说明，再继续已批准范围内的工作。

新建另一个课题：

> 在这个工作区新建一个“微带带通滤波器”课题，和现有移相器分开保存。可以检索共享 Brain 中的经验，但不要复制已有课题的批准或覆盖它的模型。

整理经验：

> 将这轮馈电与弯折调整的经验整理到 Brain，关联具体模型和曲线。说明哪些已验证、哪些只是本案例观察，不要直接推广为通用结论。

更换对话后，也应在同一研究工作区打开 Agent。课题状态保存在文件和实验记录中，不应只依赖聊天记忆。一个课题可以有多种设计和多轮尝试，旧结果保留，新结果另建版本。

## 需要帮助时

直接让 Agent 排查即可：

> 我看不到研究工具，请根据部署记录检查安装、客户端加载和知识库绑定。用普通语言告诉我问题在哪里、你已修复什么，以及还需要我做哪一步。
